# 原始陀螺仪与 EKF 配置分析

日志：log/26.11.5/log_0_UnknownDate_1.ulg。对照：log/机架1.params。时间是上电后秒数；主要统计窗口19–32 s，排除末尾停机翻倒。未修改飞控参数。

## 数据与方法

复用同一日志已有解析产物 analysis/roll_20261105_unknown1/topics.npz 和 metadata.json，重新计算三轴 FIFO 数据、Welch 频谱、估计器状态与参数差异。analyze.py 可复现本次结果。主FIFO标称2 kHz，每包2样本，按scale换算rad/s，按500 us展开；统计窗口实得25945样本，相邻间隔最大556 us。频谱重采样至2 kHz，8192点Welch。副FIFO标称dt625 us，但日志仅约1000样本/s且间隔不均，不用它插值频谱定量确认高频峰。日志无dropout不等于所有传感器原生采样都完整记录。

2–7 s是解锁前窗口，已有明显运动，尤其Z轴；不能作为静止白噪声或零偏标定依据。本日志也不适合估计Allan方差。

## 原始振动

主BMI088，gyro ID6684690；副BMI270，ID3604506。主三轴原始标准差分别2.3085、0.9060、0.3760 rad/s，最大绝对值5.8888、2.3223、1.3081 rad/s。250–350 Hz带内RMS分别2.0679、0.7688、0.2814 rad/s。X/Y主峰300.781 Hz，Z在该频带内峰318.604 Hz。原始振动幅度包含机械响应和真实运动，不是EKF预测噪声参数的直接估计值。

同日志已有转速分析显示上下桨约9178/9314 RPM，转频153/155 Hz，300 Hz接近二阶量级，仅支持转速相关机械振动嫌疑，不足以定位具体桨或轴。500 Hz sensor_gyro中的约198 Hz峰存在混叠，不能当作原始主频。

主IMU全日志gyro/accel clipping和error_count均为0；副陀螺gyro clipping为0，副加速度计末尾累计clipping=[529,0,3118]，19–32 s内Z从977增至2764。削顶告警来自副加速度计，不能认定主EKF陀螺削顶，也不能把副IMU当前当作可靠冗余。

同日志既有动捕分析支持5–6 Hz真实机体抖动：控制roll速率峰5.62 Hz，动捕roll微分峰5.47 Hz，附近相干度约0.96。该结论引用既有分析，本脚本未重新处理动捕。约300 Hz振动与5–6 Hz闭环抖动需要分别处理。

## 配置一致性与估计器状态

所有对照文件中的EKF2、IMU和SENS_IMU参数与日志最终记录数值一致（浮点容差比较）。但CAL_GYRO优先级和0/1号零偏不同。文件0/1/2号优先级25/100/50，日志最终均-1；运行sensors_status_imu两枚gyro实际priority=[1,1]且healthy=true。sensor_selection与estimator_status均确认主gyro6684690、accel6946834，未见切换。日志参数是最后记录值，解析器未保留参数变更时间，不能据此精确恢复每一时刻校准参数。文件头固件b103229335，日志固件3fef8242687cf733b590ff21c5b36779943299d1，不能把参数文件视为本次完整固件状态快照。

19–32 s：filter_fault_flags=0，四元数重置计数0；高度检验比0.0054–0.1533。gyro_bias范围X[-0.00467,-0.000539]、Y[-0.00163,0.000137]、Z[-0.001387,-0.001226] rad/s，远离0.15限幅，valid为true。没有陀螺零偏发散证据，但零数值故障不能证明姿态准确。

状态位按本仓库PX4定义解码：倾角对齐100%，航向对齐0%；GPS位置/速度、高度、磁航向/三轴磁融合、EV位置/速度/航向/高度均0%；气压高度100%；gravity_vector约92.3%。位置/速度/航向检验比NaN，不能理解为检验通过。仓库源码未证明与日志固件提交完全相同，定制固件的状态位解释仍应以对应提交核实。

## 建议

1. 优先检查桨叶、桨毂、轴系、机架固定和IMU安装，压低300 Hz振动；检查副加速度计量程/驱动配置和振动削顶。两枚陀螺都表现明显振动，不能仅归因主陀螺损坏。
2. EKF2_GYR_NOISE=0.015、GYR_B_NOISE=0.001、GYR_B_LIM=0.15、ACC_NOISE=0.35、IMU_CTRL=7基本为默认配置。当前不建议增加零偏上限、加快零偏追踪或将原始STD直接填入GYR_NOISE。没有融合创新信息充分支持某个更优噪声值。
3. 当前SENS_IMU_MODE=1、EKF2_MULTI_IMU=0是合法单EKF组合。先明确选择并验证主IMU，记录实际设备ID和优先级；副加速度削顶问题解决前，不建议直接启用双EKF或按旧文件优先级强切副IMU。
4. HGT_REF=1为GPS，但本次实际只有气压高度融合。若长期室内无GPS且主要依赖气压，可考虑设HGT_REF=0使配置符合实际；它不直接解决roll偏差。气压噪声3.5 m暂缺降低依据。GPS_CTRL=7和MAG_TYPE=0不代表这些源实际进入融合。
5. 动捕数据存在于地面分析，不等于进入EKF；本日志没有EV融合。若希望解决绝对航向和横向加速度/倾角混淆，应先打通并验证外部里程计坐标、安装外参、时间同步、延迟和噪声，再决定EV融合及高度参考参数。当前不直接给出可刷写的EV参数集。
6. IMU_CTRL=7开启重力向量约束；本仓库实现是在无水平辅助且加速度模长接近g时融合。持续水平加速度仍可能被解释为倾角，即使模长接近g。这是roll偏差的可能贡献，现有信息不能量化归因。不建议在没有可靠外部辅助时直接改为3关闭重力融合。
7. GYRO_CUTOFF=40 Hz、DGYRO_CUTOFF=30 Hz、静态/动态陷波关闭。控制角速度低通/陷波链与EKF积分IMU输入链不同，调控制陷波不能等同于消除EKF输入振动。降低截止到5–10 Hz会损伤5–6 Hz真实运动反馈并增加延迟；不建议。机械整改后如残余300 Hz窄带峰稳定，可评估控制链约300 Hz陷波；转速变化大时评估基于可靠RPM的动态陷波，先核对自定义双桨RPM单位与映射。
8. 下次补充静止预热记录、传感器原生FIFO、sensor_combined/vehicle_imu、estimator_status_flags、estimator_aid_src_gravity和外部辅助创新、原始外部里程计。现有日志没有完整创新/输入积分数据，不能确认EKF内残余高频能量或给出最优噪声参数。
