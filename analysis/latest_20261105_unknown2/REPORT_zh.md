# 2026-11-05 第三架次：200 Hz PWM 后的振荡与控制余量

ULog：`log/26.11.5/log_0_UnknownDate_2.ulg`。地面会话：`/home/ryan/TeleaiTrans_dev/Dock_ground/logs/flights/flight_20261105T071243_578Z_aircraft-01_1`。时间均为飞控上电秒数。仅分析，未修改参数或固件。

> 后续姿态专项分析修正：原始动捕刚体与飞控FRD包含接近180°的轴变换，本文表格中的原始动捕Euler角不能直接与机载Euler角相减。完成角速度外参拟合和不依赖yaw的竖直向量比较后，仍发现相对起飞前约2–4°的慢变倾角差及航向漂移。详见 `../attitude_mocap_20261105_unknown2/REPORT_zh.md`。因此持续负杆不能全部归为机械配平，机载目标跟踪好也不证明真实倾角正确。

## 判断

“共振有所缓解”有实测支持，但仍有6–7 Hz真实机体振荡，约300 Hz机械振动没有显著下降。“所有杆量都用来维持稳定”描述了持续修正的操纵负担，但这次数据不支持三轴或所有执行器长期满量程：主要表现是持续负roll配平需求、剩余动态抖动和有限的单方向力矩余量。姿态跟踪较上一架次明显改善，不能沿用上一架次“近满负roll杆仍明显跟不上”的结论。

本次参数 `PWM_MAIN_TIM1=200`、`PWM_MAIN_TIM2=200`，上次为50。与PWM提高后的改善相符，但两次并非相同扰动和工作点的受控试验，不能仅据此确定因果或实测稳定裕度。

原生舵机命令全窗口范围：Servo1 −0.840～+0.447，Servo2 −0.680～+0.546，Servo3 −0.420～+0.699，没有达到±1。两路电机在列出的窗口均没有超过0.445。端点剩余量不能直接换算实际力矩余量：仍有请求力矩±0.009 N·m限制、共模/转速比分配约束和未知负载下舵机效能。

力矩到限比例仅统计原生舵机记录中共模符合默认−0.08缩放关系、缩放未封顶、转速比分配未触边、舵机未到端点的有效样本，不能解释成全时段墙钟占比。反算用 `Mx=(servo1-common)*(-common/0.08)/72.0721436`，是模型域请求，不是实测力矩。

40–50秒：反算平均Mx约−0.00523 N·m，占负向0.009上限约58%；近似P均值−0.00101，D标准差约0.00276 N·m；由非裁剪样本反算I中位约−0.00438 N·m，接近v2的−0.0045边界。说明静态补偿加残余动态波动确实在挤占负向余量，但不是所有时刻已经耗尽。反算积分受异步记录、参考滤波和分配假设影响，不能当作机载内部trace。

## 地面站排除了什么，又留下什么

地面CSV全部为STANDBY、控制源RC、deadman=0。本次没有地面位置PID接管，不能将持续杆量归因于地面位置环自动输出。动捕100% fresh，最大年龄9.75 ms。对应机载四元数与地面转发四元数绝对点积最小约0.999998，确认匹配到同一飞行和同一姿态流。

机载和动捕roll/pitch差异会变化：20–30秒均值分别约−6.42/+3.47°与−1.26/−1.17°，40–50秒差异减小。这意味着需要检查估计、安装外参、坐标约定及振动/侧向加速度影响，不能把全部负杆都归为机械静态力矩偏置，也不能直接按两者差值修trim或宣布IMU漂移。持续平移/侧力与姿态配平同样需要分开识别。

ULog报告记录dropout总计787 ms（含多个0 ms记录）；原生控制输出记录约200 Hz，不能恢复每个500 Hz控制周期。地面message18共4211帧的内部trace时间戳全部为0，不是有效控制器内部状态，不能拿其中全零的饱和标志证明没有限幅。加速度削顶告警指Accel 1，不能据此直接认定主IMU削顶。

## 下一步

1. 优先解释持续负roll杆对应的配平/位置修正需求：在受控条件下同时核对真实水平姿态、固定刚体安装外参、格栅零差模/小差模响应、重心与推力线。先区分姿态参考偏差、侧力与静态力矩偏置，再决定机械配平或软件补偿。
2. 200 Hz配置下重新辨识执行器有效滞后与效能，再针对残余6–7 Hz整定。当前仍有真实运动，不能把整段速率反馈当噪声滤除。仅提高总力矩上限或继续堆积分，现有证据不足。
3. 约300 Hz机械振动单独排查桨/轴系/连接与IMU安装；原始振动本次没有随低频振荡一起改善。
4. 补录有效的内部未限幅/限幅力矩、积分、分配残差与实测舵角/PWM，才能更直接量化物理控制余量。本次不能给出实测增益/相位裕度。
