# 第三架次机载姿态与动捕交叉诊断

日志：`log/26.11.5/log_0_UnknownDate_2.ulg`；地面会话 `flight_20261105T071243_578Z_aircraft-01_1`。仅诊断，不改参数或固件。

## 结论

有较强证据表明机载姿态存在飞行过程中变化的低频倾角误差，不只是固定安装偏差；航向相对动捕也持续漂移。残余6–7 Hz振动是真实运动，姿态估计的数度慢变误差与之并存。持续修杆可能同时受到真实配平需求和错误倾角反馈影响，不能把全部负roll杆当成机械静态力矩不足。

这不是已经完成计量标定的绝对姿态真值实验：仍需独立验证刚体安装不滑动、轴定义、时间和动捕测量。本文量化的是相对起飞前基准的姿态一致性变化，不宣布某一瞬间的精确绝对roll真值，也不能由日志单独确定哪个传感器或具体参数是根因。

## 修正上一轮的比较方法

上一轮报告分别列出机载与动捕的原始Euler角，其中的差值不可直接解释为估计误差。用角速度独立估计刚体到飞控的固定旋转，得到接近绕x轴180°的变换，另有数度轴偏差。这是坐标/刚体定义关系，不代表飞机倒置。地面VRPN配置 `axes_from_vrpn` 为单位阵，姿态记录未经机体FRD外参标定；原样pitch/yaw符号及三轴角不能直接逐项比较。

机载目标roll与机载反馈roll的比较仍处于同一坐标约定，可用于控制器跟踪判断。此前“目标跟踪较上次改善”的结论保留，但“跟踪机载目标”不证明真实倾角正确。

## 方法：排除固定坐标偏差和航向漂移

1. 地面message19的飞控时间与主机单调时间建立偏移，四元数转发与ULog一致，使用 `timestamp_sample` 和Slerp，避免仅用日志发布时刻。
2. 由动捕相邻四元数求体轴角速度，与机载角速度拟合固定旋转B（飞控体轴向量到动捕刚体轴）和时延。主分析使用2 Hz低通，12–80秒拟合；最佳查询偏移约+14 ms，包含时间对齐/接收及滤波延迟，不能解释为精确传感器硬件延迟。角速度拟合RMSE约0.023 rad/s；三轴统一RMSE，未声称每轴均达到同精度。
3. 对每个时刻计算 `v(t) = R_mocap(t) B R_fc(t)^-1 [0,0,1]`。若机载姿态与动捕仅相差固定世界坐标和固定机体安装，v应为常向量；飞控世界yaw即使漂移，也不改变其竖直向量，因此这一指标不受自由航向偏移直接污染。
4. 使用5–7.5秒的v均值作固定基准。该段动捕位置三轴变化均小于0.4 mm，动捕角速度RMS约0.011/0.006/0.007 rad/s；v的瞬时散布中位约0.053°、95分位约0.23°。它是稳定起飞前基准，不是“刚体零角等于机身水平”的假设。
5. 以0.5 Hz低通提取慢变倾角差，排除6–7 Hz残余振动的主频影响。B来自角速度，未用低频姿态误差把结果硬拟合到零。

## 倾角变化结果

下表为慢变倾角相对起飞前基准的中位数，不是原始Euler角差：

| 飞控上电秒数 | 倾角变化中位 | 5–95分位 |
|---|---:|---:|
| 12–20 | 2.45° | 1.28–3.91° |
| 20–30 | **3.93°** | **3.65–4.16°** |
| 30–40 | 3.49° | 0.75–4.30° |
| 40–50 | **0.67°** | 0.50–1.03° |
| 50–60 | 2.78° | 1.00–3.47° |
| 60–70 | 2.10° | 1.48–2.98° |
| 70–80 | **2.29°** | 1.76–2.42° |

20–30秒差异主要沿roll相关方向；之后差异明显回落，后段随机体转向在体轴方向重新分配。这不是一个常数trim能解释的轨迹。

独立敏感性检查：以0.5–10、2–12、4–9 Hz角速度频段重拟合B和时延，20–30秒倾角中位分别约3.96/3.84/3.78°，40–50秒约0.65/0.72/0.84°，70–80秒约2.26/2.21/2.21°。早段/晚段分别拟合B也仍有数度变化。精确外参尚不确定，但“飞行中倾角差改变”对这些选择较稳健。

额外允许使用全部飞行姿态，拟合两个自由固定旋转后，完整三维残差中位仍约3.30°、95分位约6.63°；这包含航向误差，只用于说明固定变换不足，不作为独立倾角精度验证。

85秒以后处于切油门/接地阶段，倾角一致性继续变差，主加速度计也在85.037秒附近出现2次Z削顶。本报告核心判断基于12–80秒，不将接地后的约6–8°变化归为悬停漂移。

## 航向

用起飞前固定世界/机体旋转校正后，三维残差z分量从20–30秒约−3.2°，到40–50秒约−6.5°，70–80秒约−12.3°。本机倾角较小，因此可用来描述约12°量级的相对航向漂移；数值是旋转向量z分量，不是精确解耦的航向创新或磁偏角。

固定世界yaw差本身正常，但随时间累积的变化不能用固定世界yaw校准消除。本次yaw对齐标志始终为0，没有磁/EV/GNSS航向融合，绝对航向不受外部锚定。v指标排除了纯yaw偏移，因此倾角变化并不是把航向漂移误当成roll/pitch。

## EKF状态与偏置

12–80秒：

- 主gyro ID6684690，主accel ID6946834，无切换证据。主gyro削顶为0；主accel两次削顶在85秒后。副BMI270加速度计大量削顶，不能用它证明主BMI088在悬停段削顶，也不能直接把副IMU当可靠替代。
- 数值故障标志始终0，姿态重置计数0；这些只说明没有相应内部故障/重置，不能证明外部姿态精度。
- tilt_align=1，yaw_align=0；EV位置、速度、航向、高度融合均0；GNSS位置/速度、光流、磁航向/三轴磁融合均0。气压高度融合为1，惯性航位推算bit29为1。
- gravity_vector bit34约91.45%。`EKF2_IMU_CTRL=7`。按本地对应源码，重力约束在无水平辅助、加速度模长接近g等条件下启用；实际创新、拒绝和成功更新没有完整日志，标志占比不等于91.45%的样本都成功更新。
- 加速度偏置硬限幅为每轴±0.4 m/s²。X约60.234秒首次接近/到达+0.4；Y约62.473秒首次接近/到达−0.4。70–80秒均值约 `[+0.393,-0.392,+0.117] m/s²`。这是实际记录的EKF状态，不是反算控制积分。
- 陀螺偏置X约−0.00951～−0.00195、Y约−0.00154～−0.00076、Z约−0.00294～−0.00234 rad/s，远未到0.15上限。不能把“gyro bias未到限”延伸为“姿态没问题”。

0.4 m/s²相当于约2.3°的小角度重力投影；它只说明量级与观测倾角差相关，不表示某轴姿态误差精确等于2.3°，也不能将两轴界限直接相加作为实测误差。

注意：本地传感器模块显示 `vehicle_angular_velocity` 和 `vehicle_acceleration` 已扣除在线估计bias，不能将这些记录再次减去bias，或用它们与动捕的差值直接辨识未经修正的传感器零偏。图中“apparent gravity”使用该控制层低通加速度，只是旁证，不是EKF实际延迟IMU输入或创新。

## 根因判断的边界

较可信的机制是：缺少水平运动和航向外部辅助时，EKF难以区分慢变倾角、持续水平比力及加速度偏置；严重的约300 Hz振动可能进一步影响IMU有效输入。倾角差随飞行变化、加速度偏置碰边、缺少外部约束支持这一方向，但现有日志不足以将责任唯一归给重力融合、振动整流、传感器标定、温漂或某一个噪声值。

主加速度Y标度约1.165，SENS_BOARD_X_OFF约1.81°，值得核对校准和安装来源；参数数值本身不能证明校准错误。动捕刚体若发生真实安装位移，也会影响结论，需要地面独立验证。持续平移及格栅侧力仍可能产生真实配平需求，不能用本报告宣布机械因素已被排除。

## 对操纵感和下一步的影响

满roll杆只对应约10°目标；3–4°慢变倾角误差已是该目标范围的30%–40%量级。飞手为维持位置施加显著杆量，并不意味着所有杆量都变成了期望真实倾角；控制器可能是在跟随一个有偏的姿态反馈。该比例是角度量级比较，不是已分离出的精确杆量分解，也不是物理力矩消耗率。

下一步应优先：

1. 保持200 Hz PWM的对照条件，在地面独立完成刚体到FRD轴定义/安装外参、世界竖直与时间关系验证。做静止预热和多姿态记录，检查无桨时机载倾角是否与动捕固定一致。
2. 在受控桨流工况比较IMU均值、在线bias和倾角一致性，辨别转速/振动相关变化与真实侧向加速度。处理约300 Hz机械振动；副IMU削顶问题单独解决。
3. 记录 `vehicle_imu` / `sensor_combined`、`estimator_aid_src_gravity`、`estimator_status_flags`、各辅助源创新和原始外部里程计。当前缺少这些数据，不能给出可信的最优噪声/延迟参数。
4. 将动捕作为经验证的外部里程计接入并验证EKF融合，是值得推进的方向。目前只是地面显示/记录，`EKF2_EV_CTRL=0`，不会帮助机载估计。应在坐标、外参、时间和质量验证后配置；不直接照搬原始动捕四元数或打开未验证的融合开关。
5. 先解决姿态参考可信度，再重新评估格栅静态配平和控制余量。不要仅据持续负杆修改trim、扩大积分或提高力矩上限，也不建议在缺少外部辅助时直接关闭重力约束。
