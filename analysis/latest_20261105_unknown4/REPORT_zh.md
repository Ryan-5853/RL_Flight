## 姿态估计问题再现

独立以动捕四元数微分角速度与机载角速度拟合固定刚体旋转B及有效时延，避免直接相减原始Euler角。当前长段拟合最佳有效偏移约16 ms，角速度RMSE约0.0225 rad/s。B包含近180°机体/刚体轴定义转换。

指标 `v(t)=R_mocap(t) B R_fc(t)^-1 ez` 与7.4–8秒起飞前固定基准比较。若仅有固定坐标与安装偏差，v应固定；纯世界yaw漂移不改变这一竖直向量。使用0.5 Hz低通看慢变倾角差。

| 20–30 | **4.78°** |

| 60–70 | 2.84° |
| 80–90 | 3.51° |

20–30秒用此前架次拟合B或单纯x轴180°替代，分别仍约4.47°/4.70°，说明该变化不是本次B拟合的单一产物。安装外参精度和动捕刚体固定仍需独立验证，这不是绝对姿态真值标定。

用起飞前固定世界/机体关系将动捕姿态映射到飞控坐标后：20–30秒机载roll/pitch约−3.34°/+0.59°，动捕映射后约+0.13°/−2.37°。因此不能仅因机载显示−3.34°就认定真实机身仍持续左倾这么多，更不能据负roll继续决定配重方向。映射后的绝对角依赖起飞前基准，不能据此宣布飞机精确水平。

100–110秒固定坐标校正后的旋转误差z均值约−18.44°，表明航向仍在漂移；它是小倾角情况下的相对航向量级，不是独立航向创新或磁偏角。竖直向量指标不受纯yaw漂移直接影响，所以倾角变化不能全部用yaw解释。

15–110秒保存下来的419个EKF状态样本中，数值故障和四元数重置均0，重力向量状态bit34约94.0%；没有动捕位置/速度/航向、GNSS水平、光流或磁航向融合，yaw_align仍0。动捕只在地面显示和记录，不会自动修正机载姿态。

在线加速度偏置本次没有触及±0.4 m/s²，但100–110秒均值约 `[−0.329,−0.352,+0.117] m/s²`；全15–110秒记录X最低−0.353、Y最低−0.372，已较接近边界。无数值故障、未触界并不能证明倾角准确。
