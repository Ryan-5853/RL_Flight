# 单体起飞转圈：机载与地面站联合分析

## 对应日志与时间对齐

机载：log/26.11.6/log_1_UnknownDate.ulg。
地面站最新两段均属于aircraft-02（机架B、VRPN sensor 2）：

- flight_20261106T033559_414Z_aircraft-02_1.csv：主要飞行，约飞控启动后23.652–46.082秒。
- flight_20261106T033622_944Z_aircraft-02_2.csv：落地后再次解锁，约47.180–52.330秒。只看“最新文件”会错过主要飞行。

用地面站FLU四元数转FRD后的样本，与机载vehicle_visual_odometry逐样本匹配。主要飞行2244行中匹配2243行，时钟偏移中位582381.316163秒，5–95分位残差约−5.34/+5.17 ms。该对齐精度足以区分秒级转圈和指令时序。

## 判断

没有证据支持主要飞行是地面站控制参考系不一致导致。更有力的证据是：起飞初期出现真实负向偏航，当前偏航配平/执行器模型未及时压住，电机差动触及模型约束；随后同方向的遥控输入进一步参与了转向。现有日志能确定这一过程，但不能唯一分解桨反扭矩系数、上下桨映射、格栅共模效能和电机动态的贡献。

## 为什么不优先怀疑参考系

1. 地面站第一段全2244行control_source=RC、deadman=0，机载gs_mode_active=0。地面站位置/yaw外环没有接管；CSV中的target_yaw_rad不是本次实际控制目标。
2. 地面站转换后姿态与EKF不做额外世界旋转拟合时，旋转差中位0.80°、95分位1.65°。FLU与FRD的yaw符号相反属坐标变换预期，不能直接把两个原始Euler yaw相减。
3. 在31–45秒，用动捕四元数差分得到FRD机体系角速度，与机载角速度匹配。z轴相关系数0.964、回归比例约1.003，支持偏航方向与幅值一致。最佳时间偏移约−21.6 ms，包含来源、时钟与滤波效应；不是仅靠EKF融合后姿态相似来验证参考系。roll/pitch激励较小，相应匹配证据弱于yaw，不能据此宣称全轴外参已精确标定。
4. 主飞行28–46秒姿态reset counter保持1，外部航向标志持续true，逐帧三轴融合记录均成功；没有飞行中航向重置。唯一后续重置约50.524秒，属于摔落后第二段，与初始转圈不同。

## 执行器证据

当前模型通道1=上桨、通道2=下桨，正偏航通过增强通道1/减弱通道2补偿；格栅负共模在正偏航受限时回零。日志显示：

- 32–33秒，电机模型预测转速比约78.5%的样本触及1.15上限；33–34秒约87.5%。
- 同期舵面共模中位接近0，符合当前模型让出负共模以争取正向偏航能力的策略。
- 因而输出行为符合“尝试抵抗负向偏航”，不符合“外部绝对航向目标突然要求绕一圈”的解释。
- 33–34秒ESC通道1/2转速中位约10239/8085 rpm，实际比值中位约1.268，5–95分位约1.234–1.306。模型1.15约束不是实际RPM闭环，已存在明显标定/动态差异。
- 命令转速推算已正确还原FinalMotorOutputMap：模型命令=2×actuator_motors.control，再查表。直接查最终输出会错误地得到“模型限幅也超出1.15”的结论。

这些证据指向起飞yaw偏置/配平、桨/格栅效能模型与实际飞机不符，以及起飞瞬态控制余量不足；它们不能单独证明某个执行器损坏或某项系数的准确数值。台架应独立确认上下桨通道和旋向、格栅共模的实际yaw方向，再测本机上下桨的命令—RPM与反扭矩平衡。

另外，地面站名称为机架B，而固件NN_AIRFRAME_ID=1且当前工作区payload标识airframe-1（checksum 0x30298daf）。仅凭编号不同不能断定刷错机或参考系错误，但应确认此实体机是否确实对应这套执行器标定。没有逐帧内部期望力矩/分配余量日志，因此饱和结论来自最终输出和当前源码模型的反算，而非机载直接记录的内部标志。

## 第二段与数据质量

第二段有约732 ms动捕源间断，姿态翻转和约50.524秒的重置。52.171秒再次解锁后，约52.298秒即触发30°姿态保护，随后上锁。这不能用来解释第一段起飞初始转圈。

主要飞行地面站位姿均新鲜，无VRPN拒绝/时序回退；机载ULog dropout=0、滤波故障位始终0。最初转圈没有来自日志丢失的伪跳变证据。

## 下一步

先保留已验证的动捕坐标变换与延迟，不依据本次转圈反转yaw符号。优先台架检查实际yaw控制方向、共模方向、两桨标定与起飞前馈配平；之后再决定修正模型或分配策略。建议补录单体控制器的期望yaw力矩、实现力矩、分配饱和标志和积分项，才能区分前馈不准、动态滞后和控制余量不足；不宜单凭这次日志直接提高yaw增益或扩大转速比限幅。
