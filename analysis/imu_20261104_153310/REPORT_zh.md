# 校准后 15:33:10 ULog 分析

源文件：`log/26.11.4/log_0_2026-11-4-15-33-10.ulg`。时刻均为飞控启动后秒数。

## 结论

本份日志不支持“电机关闭、静置时 roll 快速漂移”：10–35 秒以及 50.8–52.5 秒姿态与角速度都相当稳定。可以清楚复现的异常发生在电机运行后：两枚陀螺的一致性变差，控制所用 p 出现持续正值，roll 约以 2.5–2.7°/s 增加；同时两枚加速度计的采样波动明显上升。随后发生左右滚转及翻覆。

当前最值得优先验证的是电机运行条件下 BMI270/BMI088 陀螺测量分歧，而不是反转 roll 或继续重复静态校准。BMI270 当前是主陀螺，其运行时测量可疑，但没有逐轴原始 gyro，不能唯一归因某一枚 IMU、某一种振动机制，也不能仅靠本架次确认哪一段角度变化完全属于假姿态。

## 静置与电机运行对照

| 区间 | roll 起止 | p 均值 | 加速度计 Z 样本标准差：BMI088 / BMI270 |
|---|---|---|---|
| 10–35 s，电机输出 NaN、未解锁 | -1.872° → -1.784° | 约 0 rad/s | 0.038 / 0.033 m/s² |
| 50.8–52.5 s，电机输出 NaN、未解锁 | -2.995° → -3.039° | -0.00016 rad/s | 0.042 / 0.033 m/s² |
| 53.8–55 s，电机运行 | -2.916° → +0.107° | +0.0431 rad/s | 4.542 / 11.343 m/s² |
| 55–56.2 s，电机运行 | +0.124° → +3.424° | +0.0472 rad/s | 3.445 / 9.014 m/s² |

- 第一段 25 秒里只变化约 0.088°，没有快速漂移。
- 电机运行后约 +0.043 rad/s = +2.47°/s，与 roll 的增长速度一致，不是只看到欧拉角跳动。
- 同期 `vehicle_acceleration` 的重力静态 roll 代理值约 -3.12°，没有随姿态解算 roll 一起增大。该代理只在静态/无明显平移加速度时可作姿态参考，不能用于代替整个飞行段的真实姿态。
- 这里的标准差来自约 50 Hz 的原始 accel topic 记录，是日志采样波动，不是高频频谱或完整振动 RMS；不单凭它宣称发生了混叠。
- 所有上述前期区间 clip_counter 均为零；不能用后期碰撞/翻转阶段的削顶解释先前的持续漂移。

## 更具体的传感器线索

设备类型由当前 PX4 `drv_sensor.h` 的 device type 与设备 ID 解码核对：

| 来源 | 设备 ID | 类型 | 参数优先级 |
|---|---:|---|---:|
| CAL_GYRO0 | 6684690 (0x660012) | BMI088 gyro | 25 |
| CAL_GYRO1 | 3604506 (0x37001a) | BMI270 gyro | 100 |
| 主要 accel | 6946834 (0x6a0012) | BMI088 accel | 50 |

启动后约 1.14 秒主 gyro 从 BMI088 选为 BMI270，此后到整个事故阶段没有再次切换；这不是事故发生时切换 IMU 引起的跳变。主要 accel 为 BMI088，组合使用不同芯片的 accel 和 gyro 本身不构成错误。

当前 PX4 `VotedSensorsUpdate::calcGyroInconsistency` 先求两枚 gyro 均值，再对各枚相对均值的矢量差低通。因此在只有两枚启用 gyro 时，topic 中每枚的一致性值约等于两者低通矢量差模长的一半：

- 10–35 秒：每枚约 0.00288 rad/s，两枚低通差约 0.00576 rad/s。
- 53.8–55 秒：每枚约 0.02113 rad/s，两枚低通差约 0.04227 rad/s。
- 55–56.2 秒：每枚约 0.02684 rad/s，两枚低通差约 0.05368 rad/s。

真实机体旋转通常应被两枚同板陀螺一致观测。上述运行时分歧与所用 p 的持续正值量级接近，是测量异常的重要证据；但该记录是模长，不含逐轴差值，不能用来反推出 BMI088 的 p 必为零，也不能直接判哪一枚正确。

EKF gyro_bias 在该区间仅约 0.0001 rad/s，未将这种约 0.04–0.05 rad/s 的运行时差异吸收。`filter_fault_flags=0` 与 gyro_healthy=true 并不能证明输出准确。

## 校准是否生效

与 15:09:54 文件比较：两枚 accel 的 offset/scale 确实更新，SENS_BOARD_X_OFF 从 -3.3868°变为 +2.1072°，Y_OFF 从 +0.2087°变为 +4.0686°。CAL_GYRO0/1 的 offset 和优先级没有变化。

这不证明校准失败：静态一致性已有改善，且陀螺运行时自动校准可能不改写持久参数。它说明静态 accel/水平校准没有消除电机运行后的异常。初始非零姿态亦不能在没有独立水平基准时判为错误。

## 下一步

最有判别力的是固定机体、具备防护的台架对照：保持当前控制器和舵机映射不变，分别以 BMI270 与 BMI088 为主 gyro 记录电机升速过程，并补采两枚 sensor_gyro/FIFO、vehicle_imu 和外部姿态。不能直接拿其中一种配置继续自由飞行来验证。

若执行主 gyro 的对照，当前参数快照中 BMI088 为 CAL_GYRO0（25），BMI270 为 CAL_GYRO1（100）；应先核对设备 ID 后再临时调整优先级。切换后必须核对实际主设备，不能只看参数设置成功。现有数据不足以承诺切换 BMI088 一定解决问题。

本次没有修改机上参数或控制代码。固件版本与上一份相同。文件解析得到 15 个有数据的 topic 实例，无记录 dropout，四元数模长和所有 topic 时间戳检查通过。地面站目录仍无本架次对应记录，无法用 14:44 的动捕对齐。

复现：运行本目录 `parse_ulog.py`，再运行 `analyze.py`（依赖 numpy/scipy）。输出 metrics.json、timeline.csv 与 imu_motor_comparison.svg。
