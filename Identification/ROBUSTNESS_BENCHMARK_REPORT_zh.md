# 未知样本鲁棒性横向评测报告

日期：2026-08-06

## 1. 目的与方法

在统一的“真实飞行”场景下，横向测试历史各条控制/辨识路线的**未知样本鲁棒性**：
固定标称 LQR、真值 LQR、离线辨识 LQR（三模型 hybrid，80% 混合）、自适应 GRU、
PID、端到端神经网络、角加速度神经网络。

- 场景：自稳恢复——初始倾角 15°、初始角速度 1 rad/s，2.5 s，虚拟飞手定高
  （LQR/神经网络方案），模拟传感器噪声；PID 使用其原生内嵌高度环。
- 未知样本：v4 测试集 8 个未见机体（每次 1 个初值，8 条 episode/单元/方案）。
- 误差注入：8 个单维误差（质量、惯量、舵效、电机推力、舵机时间常数、电机
  时间常数、传感器噪声、传感器延迟）× 3 档强度 + 5 组交叉/三维误差 × 2 档
  强度，共 35 个误差单元。
- 神经网络方案（训练于另一台机体，属于强转移场景）在代表性子集上采样：
  baseline + 8 个单维最强强度 + 5 组交叉最强档。
- 综合分（越高越好）= 100·收敛率 + 100·安全率 − 100·平均滚俯误差(rad)
  − 60·平均角速度误差(rad/s) − 20·饱和占比 − 2·高度漂移(m)。

## 3. 主要结论

1. **离线辨识/自适应 GRU 基本达到“免费真值”**：在大多数误差维度与强度下，二者
   综合分与真值 LQR 的差距在 0–5 分内，远优于固定标称（标称最差可掉到 103.6）。
   离线辨识的优势主要来自它从“该机体的正常闭环日志”中学到了舵效与动力学，
   因此对质量/惯量/舵效等误差天然不敏感。
2. **敏感度分化明显**：
   - 惯量 ×2.0：标称 104.6 → 真值 163.5 / 离线 160.4 / GRU 160.5（差距最大的一维，
     也是辨识增益价值最明显的一维）；
   - 舵效 ×0.7：标称 133.7 → 离线 162.8（几乎追平真值 163.9）；
   - 电机时间常数 ×2.0：真值 151.2 但离线 138.8 / GRU 138.7 —— 唯一辨识增益
     明显低于真值的一维（复合模型保留标称电机通道，电机 τ 大误差超出其辨识范围）；
   - 质量 ×2.0：所有 LQR 方案均受物理极限限制（1/8 机体无法配平悬停），差距很小；
   - 传感器噪声/延迟（10×噪声、+8 ms 延迟）：LQR 族几乎无退化（反馈增益天然
     稳健），PID 与神经网络不受影响的部分也无变化。
3. **PID 在 2.5 s 自稳恢复场景不收敛**（收敛率 0），但始终安全；其价值在于
   简单与可解释，不作为本场景的推荐。
4. **神经网络方案在本机体上完全失效（转移失败）**：端到端与角加速度 NN 均为
   0 安全率、负分，且对误差维度/强度不敏感——它们的退化由“训练/部署机体
   差异”主导，而不是误差注入。这一结论与 git 历史中“端到端/角加速度线接近
   PID/LQR”仅在各自训练机体上成立一致。
5. **交叉误差**：质量×舵效同时变小时辨识增益只部分追平真值（离线 134.6 vs
   真值 164.2，GRU 146.7）；质量×惯量×舵机 τ 三维组合下标称 141.9、离线
   157.7、真值 157.0 —— 辨识增益仍把标称的缺口补回大半。

## 4. 工程含义

- 部署首选：**离线辨识 LQR（80% 混合）或自适应 GRU**，二者在未知样本与
  单维/交叉误差下均接近真值增益，且不需要真值参数。
- 固定标称 LQR 作为兜底仍然可用（多数单元 ≥150），但在惯量/舵效/交叉误差
  下会明显退化；建议保留为 shadow 对照或回退选项。
- PID 仅适合不要求快速收敛的场景；神经网络方案需要在其训练机体包络内使用，
  跨机体部署前必须有专门的迁移验证。
- 电机时间常数是当前辨识的最弱维度，后续可考虑把电机通道纳入辨识目标或
  收紧该参数的先验范围。
