# 离线复合舵效辨识实验结论报告

日期：2026-08-05

## 1. 实验目的与结论摘要

本实验回答一个问题：**只使用正常闭环飞行日志（无舵角反馈、无真值参数），离线
辨识“舵指令 -> 机体角加速度”的控制等效动态，能否生成一个与真值增益性能相当、
理论上可部署的固定 LQI 增益？**

结论：

- **性能上**，合并参数后的复合阶跃响应辨识路线，其预测增益在 860 个未见机体
  × 8 初值 × 2 种子的严格配对非线性审计中，收敛率 70.0%/70.1%，相对固定复合
  标称 LQI（60.5%/60.0%）提升 **+9.5/+10.1 个百分点**（组聚类 95% CI 均不含
  零），安全率非劣、饱和占比下降，且与复合真值增益（oracle）差距不到 1 个
  百分点。
- **部署上**，该结果支持“构型级离线校准”固定增益合约的理论可行性：增益在地面
  算好后于起飞前安装，不依赖飞行中推理或在线切换。证据已达到 **HIL 候选**
  级别，但还不是飞行授权。

## 2. 方法与评估协议

### 2.1 合并参数的辨识对象

“舵效不足”和“舵机变慢”在短闭环日志中不可唯一分离（较小的效能 `G` 与较大的时间
常数 `tau` 产生相似的阶跃响应），因此不再分别回归物理参数，而是直接监督
`u -> alpha(t)` 的短时阶跃响应：三个舵指令模态（SVD 正交基）在
10/20/40/80/160 ms 五个快照下的三轴角加速度响应，共 45 个输出。

推理时把预测响应最小二乘投影到三个稳定一阶滤波器基底
（`tau = 15/40/80 ms`），约束为可用于状态空间综合的低阶动态，再合成 19 状态
LQI（固定滤波器状态仅由历史舵指令和已知死区/回差预处理递推，不使用机械舵角）。
该投影对真值响应的误差仅 `0.0056`（固定滤波器基底 NRMSE），说明等效模型容量
不是当前瓶颈。

### 2.2 数据

- `lqr_sim2real_micro_offline_logs_v2`：8192 个随机机体、每组 8 次闭环飞行，
  共 65536 次；分层多轴初始条件（倾角 5–25 deg，`p/q <= 1.5 rad/s`，
  `r <= 2.0 rad/s`）；保存前 2 s、500 Hz 完整日志；无逐通道扫频/阶跃/真值
  参数泄漏。
- 训练/验证/测试按机体参数组切分，分别保留 4037/850/860 个至少有一次成功日志
  的机体；回归只用收敛试飞。
- 测量模式为 `simulated_sensors`（陀螺/电机噪声进入控制器与特征），但姿态仍是
  仿真真值倾斜代理，**没有姿态估计器**。

### 2.3 候选与评估

- 候选模型：MLP（100 Hz，1.84M 参数）、TCN（500 Hz，307k）、BiGRU（500 Hz，
  292k），同一训练种子，全部在 1/2/4/8 次飞行下评估。
- 组合选择规则：只按**验证集逐轴 R2** 决定 hybrid 分支。
- 最终评估：860 个未见测试机体 × 8 个初始条件 × 2 s，两个独立评估随机种子；
  所有控制器共享完全相同的机体、初值、随机序列；置信区间按机体参数组聚类。

## 3. 性能对比

### 3.1 辨识精度：三种架构、1/2/4/8 次飞行

完整响应 NRMSE（测试集，越小越好）：

| 飞行次数 | MLP (100 Hz) | TCN (500 Hz) | BiGRU (500 Hz) |
| ---: | ---: | ---: | ---: |
| 1 | 0.4032 | 0.3944 | 0.4067 |
| 2 | 0.3580 | 0.3576 | 0.3646 |
| 4 | 0.3266 | 0.3315 | 0.3373 |
| 8 | **0.3082** | 0.3190 | 0.3240 |

8 次飞行测试逐轴平均 R2（验证集数值见括号）：

| 架构 | roll | pitch | yaw |
| --- | ---: | ---: | ---: |
| MLP | 0.691 (0.678) | 0.738 (0.761) | **0.452 (0.440)** |
| TCN | **0.783 (0.747)** | **0.820 (0.816)** | 0.443 (0.410) |
| BiGRU | 0.695 (0.697) | 0.759 (0.762) | 0.373 (0.386) |

结论：多次飞行带来单调改善；yaw 仍是最弱轴，但分层 yaw-rate 初始条件把 yaw R2
从旧数据的 0.306 提升到 0.44–0.45。TCN 在 roll/pitch 最优，MLP 在 yaw 最优，
BiGRU 未在任何轴胜出。**最终 hybrid = TCN(roll/pitch) + MLP(yaw)**，其完整响应
NRMSE 为 0.298。

### 3.2 控制性能：860 组严格配对非线性审计

| 控制器 | seed A 收敛率 | seed B 收敛率 | 相对复合标称 (95% CI) |
| --- | ---: | ---: | ---: |
| 原始标称 LQI | 57.94% | 57.14% | -2.56 / -2.86 pp |
| 固定复合标称 LQI | 60.49% | 60.00% | 基准 |
| hybrid 预测增益 50% | 66.90% | 67.14% | +6.41 / +7.14 pp |
| hybrid 预测增益 80% | 69.08% | 69.55% | +8.59 / +9.55 pp |
| hybrid 预测增益 90% | 69.64% | 69.88% | +9.14 / +9.88 pp |
| **hybrid 全预测增益** | **70.00%** | **70.09%** | **+9.51 [8.04, 11.03] / +10.09 [8.58, 11.61] pp** |
| 复合真值增益（oracle） | 70.19% | 70.07% | +9.69 / +10.07 pp |
| 原始真值增益（oracle） | 70.81% | 70.60% | +10.32 / +10.60 pp |

安全与饱和（全预测增益 vs 复合标称）：

| 指标 | 复合标称 | hybrid 全预测 |
| --- | ---: | ---: |
| 安全率 | 99.64% / 99.62% | 99.83% / 99.78% |
| 平均饱和占比 | 9.87% / 9.98% | 8.87% / 9.08% |
| 局部稳定比例（DARE） | 1.0 | 1.0 |
| 局部极点半径 p95 | 0.9979 | 0.9973 |

要点：

- 全预测增益的收敛提升在两个种子下均显著（CI 不含零），胜/败组数 858/204 与
  894/200；与复合 oracle 的差距仅 0.2–0.9 pp，种子 B 下甚至反超 0.02 pp。
- 混合比例扫描（393 组 × 8 初值，10%–100% 步进）显示收益随比例单调上升且
  全部显著：10% 混合即有 +1.2 pp，50% 混合有 +6.1 pp，90% 混合 +8.4 pp。
  这为保守部署提供了余量选择。
- 旧“分别辨识物理效能+时间常数”路线（legacy）收敛率反而低于复合标称
  （-5.2/-5.6 pp），是复合阶跃响应路线被采用的原因。

### 3.3 胜/败分层：收益是否挑数据？

对最终审计的逐组收敛 delta，按物理参数、日志信息量分数、主检查点输入 OOD
z-score 分层：

- hybrid 全预测增益在约 39–40% 的机体上优于复合标称、约 12% 上劣于标称，
  其余不变；
- 与日志信息量的相关可忽略（-0.04 ~ -0.08），低信息量组的平均收益甚至略高
  （+0.111/+0.133 vs +0.095/+0.097）；
- 与输入 z-score p95 的相关为弱正（+0.03 ~ +0.08），低/高 OOD 分位的平均收益
  均为正（约 +0.09 ~ +0.11）。

即优势在全部信息量/OOD 分位成立，不是依赖“日志恰好有信息”或“输入恰好接近训练
分布”的运气。对比之下 legacy 路线在高 OOD 组明显退化（z 相关 -0.17 ~ -0.20）。

### 3.4 与在线自适应路线的对比

之前的 wide-range 在线自适应实验（1 s 历史在线推理、两秒插值换增益）最终冻结为
`shadow_only`：非线性配对审计中自适应增益相对标称没有收敛优势。本离线实验的
关键差异是：

- 在线路线要求控制器在 1 s 内完成辨识并等待切换，出包线轨迹无法恢复；离线路线
  可以汇总多次试飞、在飞行间隙完成全部计算。
- 在线路线每次只有一个 1 s 历史窗口的信息量；离线路线可联合 8 次完整 2 s 日志
  并按信息量选择。
- 离线路线把“辨识质量”检查（DARE、极点、质量/OOD、饱和裕度）放到飞行前，飞行
  中不再有任何增益计算。

## 4. 部署的理论可行性

### 4.1 部署合约

本实验支持的是**构型级离线校准（fixed-gain）**合约：

```text
同构型多次正常闭环试飞（含失败前缀）
  -> 地面离线辨识（8 次日志，按信息量选择）
  -> 质量/OOD/激励门控 + DARE + 极点 + 饱和裕度（全部离线）
  -> 生成固定复合 LQI 增益与命令舵机观测器
  -> HIL 验证真实控制器栈
  -> 实机 shadow 首飞（候选不接管，只对比）
  -> 通过后下一次飞行从第一个控制周期启用
```

该合约**不需要**飞行中推理、增益切换或限速插值；飞行中也不存在“信息不足保持
上一次增益”的状态。限速插值和在线门控只属于“飞行中更新增益”路线，本报告不
以它为部署前提。

### 4.2 理论可行的依据

1. **控制等效目标消歧**：把“舵效 × 时间常数”合并成阶跃响应直接监督，消除了
   短日志中不可唯一识别的方向，网络学习的是 LQR 实际消费的等效动态。
2. **稳定基底约束**：固定正时间常数的滤波器基底保证执行器子系统自身稳定，并把
   45 维预测约束到状态空间综合可用的低阶模型；其对真值响应的投影误差仅 0.006，
   即等效模型容量足够，当前误差主要来自辨识网络而不是表示。
3. **综合稳定性**：全部 860 组测试机体的 DARE 成功且增益有限，局部真值模型
   稳定比例 100%，预测增益的极点半径 p95（0.9973）优于标称（0.9979）。
4. **闭环优势可复现**：相对固定复合标称的安全非劣和收敛优势在两个独立评估种子
   上成立，组聚类 95% CI 均不含零；全预测增益几乎追平 oracle，说明性能边界已
   接近“用真值增益”能达到的上限。
5. **保守余量存在**：即使只采用 50% 混合，仍有 +6.4/+7.1 pp 的显著收益，且饱和
   与安全都不变差；部署可以选择更保守的混合比例换取更大的鲁棒余量。
6. **收益不挑数据**：所有信息量/OOD 分位均为正收益，意味着只要日志通过质量
   门控，候选增益的优势预期在分布内成立。

### 4.3 理论边界（为什么还不是飞行授权）

1. **仿真代理假设**：姿态是 SimEnv 真值倾斜代理，回路中没有姿态估计器；本数据
   集覆盖陀螺/电机噪声与延迟，但未覆盖估计器误差、偏置与延迟的组合。
2. **辨识精度有限**：响应 NRMSE 0.30 远大于基底投影误差 0.006；yaw 与舵机动态
   仍是弱辨识（yaw R2 ~0.44，旧数据舵机 tau R2 ~0.04–0.24）。当前性能靠“鲁棒
   合成 + 混合”而不是“精确辨识”，因此不能说参数被复原。
3. **评估时长有限**：严格配对审计为 2 s；30 s 级长时表现、未建模气动/结构振动/
   执行器漂移/硬件故障均未覆盖。
4. **Sim2Real 未量化**：命令缩放、执行器接口、时序、固件差异在仿真中不存在，
   必须由 HIL 补上，这是“理论可行”到“工程可飞”之间不可跳过的桥。

### 4.4 部署前必做项（离线合约）与可选增强

必做：

1. **离线接受门控**：对候选增益执行 DARE、非有限/极点恶化、输入质量/OOD/激励、
   饱和裕度检查；不通过则维持标称/混合控制器（本实验的分层工具与质量校准阈值
   已就绪，`offline_log_quality_calibration_v1.json`）。
2. **HIL**：在真实控制器栈（姿态估计器、真实命令链路与时序）上复跑本评估协议。
3. **实机 shadow 首飞**：候选增益只记录不接管，与标称逐次对比后再启用。

可选增强（进入飞行中更新路线时才需要）：按时间限速的增益插值与切换瞬态验证、
在线不确定度/激励/饱和门控、原子回退到标称增益。

## 6. 一句话结论

离线复合舵效辨识在控制性能上已达到“与真值增益几乎相当、跨种子可复现、收益不挑
数据”的水平，作为构型级离线固定增益合约**理论可行**，当前证据等级为
**HIL 候选**；完成离线接受门控、HIL 与 shadow 首飞三项后，才具备飞行授权条件。
